## Website project: how the work is split

- One direction check up front: references, page plan, assets, key decisions. After that I keep going without asking again section by section.
- `haiku`: asset inventory, reference searches, link and image checks.
- `sonnet`: SEO (titles, metadata, markup), accessibility, alt text, small touch-ups.
- `opus`: multi-page implementation, shared components, responsive layout.
- Tier above opus, only when I ask for it: design system and final review. Otherwise opus.
- Useful sub-agents here: asset inventory, reference search, SEO audit. Each returns a short list.
- Creative direction (tone, layout, visual choices) stays in the main context: I do not delegate it.
